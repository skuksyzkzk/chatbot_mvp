# 간단한 AI 챗봇 (Streamlit)

Streamlit으로 만든 간단한 AI 챗봇 웹앱입니다.

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 주요 기능
- 채팅 인터페이스 (메시지 입력창)
- 대화 기록 표시 (사용자/봇 구분)
- 간단한 응답 생성 (고정 응답/패턴 매칭)
- 대화 내역 세션 유지

## 배포 방법 (Streamlit Cloud)
1. 이 프로젝트를 GitHub에 업로드
2. [Streamlit Cloud](https://streamlit.io/cloud)에서 리포지토리 연결 후 배포
